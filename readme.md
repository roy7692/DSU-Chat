# 🎓 DSU AI Chatbot

A production-style AI chatbot for Dayananda Sagar University built using:

- Streamlit (UI)
- Ollama (Local LLM)
- Python

## Features
- DSU-specific query handling
- Chat memory
- Clean UI
- Local inference (no API cost)

## Run

```bash
pip install -r requirements.txt
streamlit run app.py
